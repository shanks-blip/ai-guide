웹·PC·휴대폰에서 시작하기 입문

추가 · 2026-09-28

Claude는 브라우저(웹), PC 앱(Windows·Mac), 휴대폰 앱 어디서든 같은 계정으로 씁니다. 대화 기록은 모든 기기에서 이어집니다. 처음이라면 웹으로 시작하고, 매일 쓰게 되면 PC 앱을 까는 순서를 권합니다.

1) 웹에서 — 설치 없이 바로

1
claude.ai에 접속합니다. 크롬·엣지·사파리 어느 브라우저든 됩니다. 비슷한 이름의 가짜 사이트가 있으니 주소를 꼭 확인하세요.
2
Google 계정이나 이메일로 가입합니다. 이메일로 가입하면 받은 편지함에 온 로그인 링크를 누르면 됩니다.
3
가운데 입력창에 질문을 씁니다. 파일은 입력창 왼쪽 ＋로 붙이고, 모델은 입력창 오른쪽의 모델 이름을 눌러 바꿉니다.

2) PC 앱에서 — Windows·Mac

PC 앱은 웹과 기능이 거의 같지만, 내 컴퓨터의 폴더를 직접 열어 파일을 정리·수정하는 일은 PC 앱에서만 됩니다. 회사 PC라 설치가 막혀 있다면 웹으로 쓰면 됩니다(→ 회사 PC에서 AI 쓰기).

1
claude.com/download에서 설치 파일을 받습니다. 일반 Windows PC는 Download for Windows, 서피스처럼 ARM 칩 노트북은 Windows (arm64)를 누릅니다. Mac은 macOS 옆 Download를 누릅니다.
2
받은 파일을 실행해 설치합니다. Windows 10 이상, macOS 11 이상이면 됩니다. 설치가 끝나면 시작 메뉴(Mac은 응용 프로그램 폴더)에서 Claude를 엽니다.
3
웹과 같은 계정으로 로그인합니다. 웹에서 하던 대화가 그대로 보입니다.
4
(Mac) 빠른 호출을 켜 둡니다. Mac에서는 Option 키를 두 번 누르거나 Option+Space로 어느 화면에서든 Claude를 불러낼 수 있습니다. 이 기능은 아직 Windows에는 없습니다.

3) 휴대폰에서

앱스토어(아이폰)나 구글 플레이(안드로이드)에서 ‘Claude’를 검색해 Anthropic이 만든 앱을 받습니다. 사진을 찍어 바로 물어보거나 음성으로 대화할 때 편하고, PC 앱을 켜 둔 상태라면 휴대폰에서 일을 맡기고 결과를 받아 볼 수도 있습니다.

4) 크롬 확장 — Claude in Chrome

유료 플랜 사용자는 크롬 웹스토어에서 Claude in Chrome을 추가하면, 보고 있는 웹페이지를 Claude가 읽고 클릭·입력까지 대신 해 줄 수 있습니다(베타). 처음에는 믿을 만한 사이트만 허용하고, 결제·전송 같은 동작은 매번 묻도록 두세요.

어디서 쓸까좋은 점알아 둘 점
웹 (claude.ai)설치 없음, 회사 PC에서도 대개 가능내 PC 폴더를 직접 다루지는 못함
PC 앱내 폴더·파일 직접 작업, 로컬 도구 연결작업 중에는 앱을 켜 두고 PC가 잠들지 않게
휴대폰 앱사진·음성으로 바로 질문, 이동 중 확인긴 문서 편집은 PC가 편함

첫 대화와 모델 고르기 입문

업데이트 · 2026-09-29

Claude는 Anthropic이 만든 AI 어시스턴트입니다. 한국어로 평소 말하듯 쓰면 되고, 명령어를 외울 필요는 없습니다.

1
입력창에 부탁을 씁니다. “누구에게·무엇을·어떤 형식으로”를 함께 적으면 결과가 좋아집니다(→ 결과를 좋게 만드는 습관).
2
파일·사진은 ＋로 붙입니다. PDF·엑셀·이미지를 끌어다 놓아도 됩니다. 입력창에 /를 치면 쓸 수 있는 기능 목록이 나옵니다.
3
모델은 입력창 오른쪽에서 바꿉니다. 평소엔 기본값 그대로 두고, 어려운 분석이 필요할 때만 상위 모델이나 ‘깊이 생각하기’(확장 사고)를 켜세요.

꼭 쓰는 핵심 기능

기능은 많지만, 처음엔 아래 다섯 가지만 알아도 충분합니다. 대부분 입력창 왼쪽 ＋ 메뉴나 왼쪽 사이드바에서 찾을 수 있습니다.

① Docs·Slides·Design — 대화하며 문서·발표자료 만들기

“이 회의록으로 임원 보고 슬라이드 8장 만들어 줘”라고 하면, 대화 옆에 바로 고칠 수 있는 슬라이드가 열립니다. 글자를 직접 고치거나 요소를 옮길 수 있고, “3장 그래프를 막대로 바꿔 줘”처럼 말로 고쳐도 됩니다. 완성본은 링크로 공유하거나 PPT·PDF로 내보냅니다(Pro 이상). 자세한 활용은 문서·슬라이드 활용 사례를 보세요.

② 프로젝트 — 같은 일은 한곳에 모아서

주간 보고, 특정 고객 업무처럼 반복되는 일은 프로젝트를 만들어 관련 파일과 지침(“항상 존댓말, 요약 먼저”)을 넣어 두세요. 그 안에서 여는 대화는 매번 같은 자료와 규칙을 따릅니다. 프로젝트는 현재 ‘여러 대화를 동시에 이어 가는’ 방식으로 개편되는 중이라, 계정에 따라 화면이 조금 다를 수 있습니다.

③ 메모리 — 나를 기억하는 Claude

무료 플랜에도 대화 간 메모리가 있습니다. 내 직무, 자주 쓰는 형식 같은 것을 기억해 다음 대화에 반영합니다. 설정에서 무엇을 기억하는지 확인·수정·삭제할 수 있으니, 원치 않는 내용이 쌓였다면 지우면 됩니다.

④ 웹 검색·리서치 — 최신 정보가 필요할 때

오늘 환율, 최근 뉴스처럼 학습 이후의 정보는 웹 검색으로 가져옵니다. 여러 출처를 오래 뒤져 보고서로 묶어야 하면 리서치를 켭니다. 어느 쪽이든 답에 붙은 출처 링크를 직접 열어 확인하는 습관을 들이세요.

⑤ 연결 앱·플러그인 — 내 도구와 이어 붙이기

일 맡기기 — 옛 Cowork, 이제는 기본 기능 중급

업데이트 · 2026-09-28

예전엔 ‘Cowork 탭’을 따로 눌러야 했던 기능입니다. 지금은 대화창에서 “이 폴더 정리해 줘”, “매주 월요일에 보고서 만들어 줘”처럼 일을 통째로 부탁하면, Claude가 계획을 세우고 파일을 만들어 결과를 돌려줍니다. 답을 ‘알려 주는’ 것을 넘어 ‘해 놓는’ 단계라고 보면 됩니다.

웹과 PC 앱, 무엇이 다른가

하고 싶은 일웹·휴대폰PC 앱
올린 파일로 문서·표·슬라이드 만들기가능가능
연결 앱(드라이브·메일 등) 자료로 작업가능가능
내 PC 폴더의 파일을 직접 열고 정리·저장불가가능 (폴더 접근 허용 필요)
정해진 시간에 반복 실행(예약 작업)Pro 이상에서 가능 — 내 PC 파일을 쓰는 예약은 그 시간에 PC와 앱이 켜져 있어야 함

사용 방법

1
(내 파일을 다룰 때) PC 앱을 엽니다. 최신 버전인지 확인하세요. 웹에 올린 파일이나 연결 앱 자료만 쓴다면 웹에서도 됩니다.
2
할 일을 결과물 기준으로 설명합니다. “receipts 폴더 영수증으로 월별 합계 엑셀을 만들어 줘. 파일 이름은 2026-09_경비.xlsx”처럼 어디서 무엇을 어떤 파일로를 적습니다.
3
폴더 접근을 허용합니다. Claude가 필요한 폴더를 묻으면 그 폴더만 허용합니다. 파일을 지우는 일은 항상 따로 확인을 받습니다.
4
계획을 먼저 보고 승인합니다. 기본 설정은 ‘행동하기 전에 묻기’입니다. 익숙해지면 설정에서 알아서 진행하고 문제가 있을 때만 묻도록 바꿀 수 있지만, 중요한 파일이 걸린 일은 기본값을 권합니다.
5
반복되는 일은 예약합니다. “매주 월요일 오전 9시에 이 보고서를 새로 만들어 줘”처럼 말하면 예약 작업으로 등록됩니다.
한 번 적어 두면 계속 적용 — 기본 지침

“나는 마케팅팀 실무자야. 결과 문서는 한국어 존댓말, 맨 앞에 3줄 요약. 표는 .xlsx로, 파일 이름은 YYYYMMDD_주제.”

결과

설정의 개인 지침이나 프로젝트 지침에 넣어 두면, 이후 맡기는 일이 모두 이 규칙을 따릅니다. 매번 형식을 다시 설명하지 않아도 됩니다.

문제 해결

증상원인처방
내 PC 폴더를 못 연다웹에서 요청함PC 앱에서 같은 대화를 열고 폴더 접근을 허용
작업이 도중에 멈춘다앱을 닫았거나 PC가 절전 상태작업 중엔 앱을 켜 두고 절전을 끄기
사용량이 금세 바닥난다파일 작업은 일반 대화보다 많이 씀간단한 질문은 그냥 대화로, 여러 파일을 다루는 일만 맡기기
(Windows) ‘VM service not running’구버전 설치본 또는 가상 환경 서비스 중지공식 다운로드 페이지에서 재설치 후 최신 버전으로 업데이트
엉뚱한 파일을 건드릴까 걱정대상 범위가 모호“이 폴더만”, “원본은 그대로 두고 새 파일로”를 명시하고 계획부터 받기
바로 써 볼 예시는 다음 절 일 맡기기 실전 예시에 있습니다. 폴더 정리·영수증→엑셀·회의록→슬라이드·예약 작업까지 붙여 넣기만 하면 됩니다.
Cowork is now Claude (공식 발표) ↗승인 방식·예약 작업·적용 순서 (영문) 파일 작업 시작하기 (공식 도움말) ↗폴더 연결·권한·첫 작업 단계별 안내 (영문, 옛 Cowork 문서)

일 맡기기 실전 예시 중급

업데이트 · 2026-09-28

일 맡기기가 빛나는 순간은 반복적이고 여러 단계가 필요한 파일 작업입니다. 바로 붙여넣을 수 있는 예시 프롬프트를 모았습니다.

다운로드 폴더 자동 정리

수개월치 다운로드 폴더를 종류·날짜별로 자동 분류합니다. 계획 먼저 보여주기를 요청해 실행 전에 검토하세요.

내 다운로드 폴더를 스캔해서 파일을 종류(문서/이미지/영상/압축파일/기타)와 연도-월 기준으로 정리할 계획을 먼저 보여줘. 예상 폴더 구조와 이름 규칙, 중복 파일 처리 방법, 삭제가 필요할 파일 목록도 포함해줘. 내가 승인하면 그때 실행해줘.
결과 예시

Claude가 폴더를 스캔한 후 아래와 같이 계획을 제시합니다:

  • 2025-문서 — .pdf, .docx, .xlsx 파일 47개 이동 예정
  • 2026-이미지 — .png, .jpg, .gif 파일 123개 이동 예정
  • 중복 파일 — 12개 감지, 최신본 유지 후 나머지 삭제 대상(삭제는 별도 승인)

승인 후 실제 폴더 이동이 실행됩니다. 삭제는 추가 확인창이 뜹니다.

영수증 사진 → 경비 정산 엑셀

스마트폰으로 찍은 영수증 이미지들을 폴더에 모아두면, Claude가 날짜·항목·금액을 추출해 합계 수식과 차트가 달린 엑셀 파일로 만들어줍니다.

이 폴더(receipts/)에 있는 영수증 사진 전부에서 날짜·가맹점명·항목·금액·부가세를 자동으로 추출해줘. 추출한 데이터를 열별로 정리하고, 월별 합계 행과 항목 분류별 파이 차트가 있는 경비 정산표(expense_2026.xlsx)로 저장해줘.
팁: 영수증이 흐릿하거나 글씨가 작은 경우 "인식이 불확실한 항목은 별도 시트에 표시해줘"라고 추가하면 나중에 검토하기 쉽습니다.

회의록 → 임원 보고 PPT

텍스트 회의록 파일만 있으면 슬라이드 구조를 Claude가 알아서 잡고 완성된 PowerPoint 파일을 만들어줍니다.

meeting_notes_0615.txt 파일을 읽어서 임원 보고용 PowerPoint를 만들어줘. 슬라이드 구성: 1장 표지(회의 제목·날짜·참석자), 2장 핵심 결론 요약, 3-6장 안건별 논의 내용·결정사항, 7장 액션 아이템 표(담당자·기한), 8장 다음 회의 일정. 전문적인 디자인으로 meeting_report.pptx 파일로 저장해줘.
결과 예시

Claude가 회의록을 분석한 후 meeting_report.pptx 파일을 지정 폴더에 생성합니다.

완료 후 "7장 액션 아이템 표의 담당자 열 폰트 크기를 키워줘"처럼 수정 요청도 바로 이어서 할 수 있습니다.

/schedule — 정기 자동 실행 예약

입력창에 /schedule을 입력하면 작업을 정해진 시간에 자동 반복 실행하도록 예약할 수 있습니다.

/schedule 매주 월요일 오전 9시에 reports/ 폴더의 지난 주 데이터 파일들을 읽어서 주간 KPI 대시보드 보고서를 생성하고 weekly_report_YYYYMMDD.docx 형태로 저장해줘.
사용법: 입력창에 /schedule을 먼저 입력하면 예약 옵션 설정 화면이 나타납니다. 반복 주기(매일·매주·매월)와 실행 시간을 선택한 후 작업 내용을 입력합니다.
사용량 주의: 파일을 다루는 작업은 일반 대화보다 사용량을 훨씬 빠르게 씁니다. 간단한 질문이나 한 번의 생성은 일반 대화를, 여러 파일을 다루는 다단계 작업은 일 맡기기를 사용하는 것이 가장 효율적입니다. 사용량이 초과되면 다음 리셋 시까지 대기하거나 플랜 업그레이드를 검토하세요.
계획 먼저 요청해 보기

“receipts 폴더의 영수증에서 날짜·금액을 뽑아 월별 합계 엑셀로 만들어 줘. 실행 전 계획부터 보여 줘.”

결과

Claude가 폴더를 훑어 추출 계획과 예상 표 구조를 먼저 보여 주고, 내가 승인하면 그때 expense.xlsx를 만듭니다. “인식이 흐린 항목은 따로 표시해 줘”라고 덧붙이면 나중에 검토하기 쉽습니다.

심화 — API · Claude Code · MCP 고급

Claude API 기초

Anthropic Console(platform.claude.com) ↗에서 API 키를 발급하고, Quickstart ↗ 문서를 따라 첫 메시지를 호출합니다.

핵심 엔드포인트는 Messages API로, 다중 턴 대화·시스템 프롬프트·도구 사용(tool use)·파일 입력을 지원합니다. 스트리밍, 확장 사고, 구조화 출력, 프롬프트 캐싱, 비전/PDF 처리도 사용할 수 있습니다.

시작 방법: Console → API Keys → 새 키 생성 → Quickstart 문서 참고 → 첫 curl 또는 Python 호출.

Claude Code — 에이전트 코딩 도구

코드베이스 전체를 이해해 파일 편집·명령 실행·Git 커밋·테스트까지 수행하는 개발자용 CLI 도구입니다. 터미널·VS Code·JetBrains 통합·웹(claude.ai/code ↗)에서 사용 가능합니다.

설치

macOS / Linux:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

설치 후 원하는 프로젝트 폴더로 이동해 claude를 실행합니다. 프로젝트 루트에 CLAUDE.md 파일을 두면 프로젝트 지침이 자동 적용됩니다.

팁: CLAUDE.md에 코딩 컨벤션, 금지 명령, 빌드 방법 등을 적어두면 Claude Code가 프로젝트를 더 잘 이해합니다.

자세한 내용은 심화 활용 페이지에서 다룹니다.

MCP (Model Context Protocol)

Anthropic이 발표한 오픈 표준으로, AI 모델과 외부 도구·데이터 소스를 안전하게 연결하는 프로토콜입니다. USB-C처럼 어떤 도구든 표준 방식으로 Claude에 연결할 수 있습니다.

Google Drive 커넥터클라우드 파일 직접 읽기·쓰기
Slack 커넥터채널 메시지 읽기·전송
GitHub 서버PR·이슈·코드 연동
웹 검색·스크래핑실시간 정보 가져오기

MCP 서버 목록과 사양은 modelcontextprotocol.io ↗와 공식 서버 모음 ↗에서 확인하세요. 자세한 연결 방법은 심화 활용 페이지를 참고하세요.

네. 무료 플랜으로 웹·PC·휴대폰에서 대화, 웹 검색, 파일 만들기, 대화 간 메모리, 앱 연결, 아티팩트를 쓸 수 있습니다. 사용량에 제한이 있어 많이 쓰면 잠시 기다려야 하고, Docs·Slides·Design과 일 맡기기·예약, Claude Code는 Pro 이상에서 쓸 수 있습니다.

Cowork 탭이 사라졌어요. 어디로 갔나요?

2026년 9월 16일부터 Cowork가 일반 대화와 합쳐졌습니다. 따로 탭을 고를 필요 없이 대화창에서 일을 부탁하면 됩니다. 예전 대화·프로젝트·아티팩트·연결 앱·스킬은 그대로 남아 있습니다. Pro·Max부터 먼저 바뀌고 Team·Free는 조금 늦게 바뀌니, 아직 예전 화면이라면 기다리면 됩니다.

꼭 PC 앱을 깔아야 하나요?

아닙니다. 대부분의 기능은 웹(claude.ai)에서 됩니다. 다만 내 컴퓨터 폴더의 파일을 Claude가 직접 열어 정리·수정하게 하려면 PC 앱이 필요합니다.

한국어는 잘 되나요?

잘 됩니다. 한국어로 물으면 한국어로 답합니다. 항상 한국어로 받고 싶다면 설정의 개인 지침이나 프로젝트 지침에 “항상 한국어로 답해 줘”라고 적어 두세요.

내 대화가 AI 학습에 쓰이나요?

개인 플랜(Free·Pro·Max)은 설정의 개인정보 항목에서 대화를 모델 개선에 쓸지 직접 고를 수 있습니다. 회사 계정(Team·Enterprise)과 API는 기본적으로 학습에 쓰이지 않습니다. 정책은 바뀔 수 있으니 설정 화면과 공식 개인정보 안내를 확인하고, 민감한 정보는 애초에 넣지 않는 것이 가장 안전합니다(→ 내 정보 지키기).

만든 문서·슬라이드는 어떻게 공유하나요?

Docs·Slides·Design으로 만든 결과물은 공유 링크로 보낼 수 있고, PPT·PDF로 내려받을 수도 있습니다. 아티팩트(대화 옆에 뜨는 결과물)도 공유 버튼으로 링크를 만들 수 있습니다.

일을 맡겨 놓고 앱을 끄면 어떻게 되나요?

내 PC 파일을 다루는 작업은 앱이 켜져 있고 PC가 깨어 있어야 계속됩니다. 앱을 닫거나 PC가 잠들면 중간에 멈출 수 있으니, 긴 작업을 맡길 때는 절전을 꺼 두세요.
