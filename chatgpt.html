지금의 ChatGPT — 2026년 9월 기준 입문

업데이트 · 2026-09-28

OpenAI가 만든 AI 어시스턴트입니다. 질문에 답하고, 문서·사진을 읽고, 웹을 검색하고, 이미지를 만들고, 음성으로 대화하는 기본기는 그대로입니다. 여름 이후 크게 달라진 점은 ‘묻고 답하기’를 넘어 일을 통째로 맡기는 쪽으로 넓어졌다는 것입니다. 쉽게 말해 채팅은 ‘상담’, 업무 모드는 ‘일을 맡기는 대리’, Codex는 ‘개발자 동료’에 가깝습니다.

갈래무엇을 하나이럴 때
채팅질문·요약·번역·글쓰기, 이미지 만들기, 음성 대화대부분의 일상 업무
업무 모드 (Work)오래 걸리는 일을 알아서 처리해 문서·스프레드시트·발표자료로 만들어 줌“여러 자료를 모아 보고서로 만들어 줘” 같은 일. Plus 이상에서 넉넉히, 무료·Go는 PC 앱에서 제한적으로
Codex코드를 읽고 고치고 실행하는 코딩 에이전트개발 업무 (→ Codex)

석 달 사이 달라진 것

  • 모델 — 채팅의 기본은 무료·Go가 GPT-5.6 Luna, 유료가 GPT-5.6 Sol입니다. 9월에 나온 GPT-6 계열(Astra·Sol·Luna)은 주로 업무 모드와 Codex에서 쓰입니다.
  • 플러그인 — 7월부터 ‘앱 디렉터리·커넥터’가 플러그인으로 정리됐습니다. 사이드바의 ‘플러그인’에서 Gmail·Google 드라이브·Slack 같은 연결을 설치합니다.
  • 맞춤형 GPT 종료 예정 — 새 GPT 만들기는 10월 26일에 끝나고, 기존 GPT는 12월 11일 종료됩니다. 쓰던 GPT가 있다면 플러그인으로 옮겨 두세요(→ 핵심 기능).
  • 새 PC 앱 — 채팅·업무 모드·Codex를 한 앱에 담은 새 데스크톱 앱이 나왔고, 예전 앱은 ‘ChatGPT Classic’으로 이름이 바뀌었습니다.

첫 대화 & 기본 설정

1
입력창에 평소 말투로 부탁합니다. 파일·사진은 입력창 왼쪽 ＋로 붙이고, @를 치면 설치한 플러그인을 불러 쓸 수 있습니다.
2
어려운 문제는 ‘생각하기’를 켭니다. 무료는 입력창의 생각하기(Think) 버튼, 유료는 생각의 깊이를 고르는 조절 막대로 바꿉니다. 깊게 생각할수록 느리고 사용량을 더 씁니다.
3
설정 세 가지를 해 둡니다. 맞춤 지침(“한국어 존댓말, 결론 먼저”), 메모리(기억할 내용 확인·삭제), 데이터 관리(내 대화를 학습에 쓸지 선택).
입력 (파일 첨부)

회의록 PDF를 ＋로 붙이고 “3줄 요약 + 내 할 일만 목록으로”

결과

핵심 3줄과 ‘내 할 일’ 목록이 나뉘어 나옵니다. 근거가 궁금하면 “어느 부분에서 나온 내용이야?”라고 되물어 확인하세요.

웹·PC·휴대폰에서 시작하기 입문

추가 · 2026-09-28

같은 계정이면 어디서 쓰든 대화가 이어집니다. 처음엔 웹으로 써 보고, 업무 모드·Codex까지 쓰려면 PC 앱을 까는 순서를 권합니다.

1) 웹에서 — chatgpt.com

1
chatgpt.com에 접속합니다. 로그인하지 않아도 간단한 질문은 바로 해 볼 수 있습니다.
2
오른쪽 위 ‘무료로 회원 가입’을 눌러 이메일이나 Google·Microsoft·Apple 계정으로 가입합니다. 카드 등록은 필요 없습니다.
3
입력창에 질문을 씁니다. 사이드바의 ‘심층 리서치’, ‘이미지’, ‘플러그인’은 필요할 때 누르면 됩니다.

2) PC 앱에서 — Windows·Mac

1
chatgpt.com/download에서 설치 파일을 받습니다. Windows에서 접속하면 ‘Windows용 다운로드’ 버튼이 뜹니다.
2
설치 후 같은 계정으로 로그인합니다. 새 앱은 채팅·업무 모드·Codex를 한곳에 담았고, 이메일·스크린샷·파일 등 작업 중인 내용을 보여 주며 대화할 수 있습니다.
3
예전 앱을 쓰고 있었다면 앱 안의 안내에 따라 새 앱으로 옮기면 됩니다. 예전 앱(ChatGPT Classic)은 보안·모델 업데이트만 받습니다.
플러그인 중에는 ‘데스크톱 전용’이 있습니다. 웹에서도 찾아볼 수는 있지만, 설치·사용은 PC 앱에서만 됩니다. 휴대폰에서는 쓸 수 없습니다.

3) 휴대폰에서

앱스토어·구글 플레이에서 OpenAI가 만든 ‘ChatGPT’ 앱을 받습니다. 음성 대화와 사진 찍어 묻기에 편하고, Plus 이상이면 휴대폰에서도 업무 모드를 쓸 수 있습니다. 앱과 웹에서 따로 구독하면 이중 결제가 되니 한 곳에서만 결제하세요.

어디서잘 맞는 일알아 둘 점
웹설치 없이 채팅·검색·이미지·심층 리서치회사 PC에서도 대개 사용 가능
PC 앱업무 모드·Codex, 데스크톱 전용 플러그인무료·Go는 업무 모드·Codex가 제한적
휴대폰 앱음성 대화, 사진 질문, 이동 중 확인앱 결제와 웹 결제를 섞지 않기
ChatGPT 다운로드 (공식) ↗Windows·Mac·휴대폰 앱과 크롬 확장 새 데스크톱 앱으로 옮기기 (OpenAI 공식) ↗새 앱과 ChatGPT Classic의 차이 (영문)

핵심 기능 깊이 보기

업데이트 · 2026-09-28

ChatGPT는 단순 답변 AI가 아닙니다. 아래 다섯 가지 기능을 알아 두면 활용도가 크게 올라갑니다. 9월 기준으로 ‘맞춤형 GPT’ 대신 업무 모드와 플러그인을 넣었습니다.

음성 대화 (Voice)

입력창 오른쪽 마이크 아이콘을 누르면 실시간 음성 대화가 시작됩니다. 고급 음성 모드는 자연스럽게 끼어들기, 감정 표현, 웃음소리도 인식합니다. 운전 중·요리 중에 손을 쓰지 않고 ChatGPT를 쓸 수 있습니다.

  • 모바일 앱에서 가장 편리하게 사용
  • 한국어 음성 인식·출력 지원
  • 회의 중 간단한 메모·번역·검색에 유용
음성 입력 (예)
다음 주 월요일 오전 회의 안건을 영어로 번역해줘. "1. 2분기 매출 검토, 2. 신규 파트너 계약 논의"
결과 (영어 음성으로 읽어줌)

Meeting Agenda for Next Monday Morning
1. Q2 Sales Review
2. Discussion on New Partner Contracts

Canvas — 옆 창 공동 편집

Canvas를 열면 ChatGPT가 생성한 글·코드가 오른쪽 편집 창에 펼쳐집니다. 복사·붙여넣기 없이 특정 단락만 선택해 "이 부분 더 간결하게"라고 요청하거나, 직접 타이핑해 수정할 수 있습니다. 긴 보고서·기획안 작성에 매우 효과적입니다.

  • 부분 선택 → 인라인 수정 지시 가능
  • 코드의 경우 특정 함수만 리팩터링 요청
  • 내보내기(복사·다운로드)로 작업 완료
입력
Canvas에서 2분기 성과 보고서 초안 작성해줘. 3개 섹션: 매출 요약 / 주요 성과 / 다음 분기 계획
결과

Canvas가 열리며 보고서 초안이 생성됩니다. 각 섹션을 드래그로 선택 후 "이 부분 좀 더 구체적으로"라고 수정 요청할 수 있습니다.

Deep Research

단순 검색이 아닙니다. ChatGPT가 수십 개 출처를 자동 탐색하고, 각주가 달린 리포트를 작성해줍니다. 시장 조사, 경쟁사 분석, 논문 리뷰 같은 작업을 몇 분 안에 처리합니다. 무료는 제한적으로, Plus 이상은 넉넉하게 쓸 수 있습니다.

  • 자동 웹 탐색 → 인용 출처 표시
  • 검색 과정·중간 결과 실시간 확인
  • 최종 리포트 다운로드 가능
Deep Research 요청
2026년 글로벌 전기차 배터리 시장을 국가별로 비교 분석하고, 출처를 포함한 리포트를 작성해줘.
결과 (요약)

탐색된 출처 32개 기반 리포트:
• 중국: 글로벌 점유율 약 65%, CATL 독주 [출처: BloombergNEF 2025]
• 미국: IRA 보조금으로 국내 생산 급증 [출처: DOE 2026]
• 한국: 삼성SDI·LG에너지솔루션 유럽 진출 가속...

업무 모드(Work)와 플러그인

업무 모드는 긴 일을 맡기는 곳입니다. “지난달 영업 자료를 모아 임원 보고 슬라이드로 만들어 줘”처럼 부탁하면, ChatGPT가 스스로 단계를 나눠 처리하고 문서·스프레드시트·발표자료로 돌려줍니다. 매주 반복되는 일은 예약 작업으로 걸어 둘 수 있습니다.

플러그인은 Gmail·Google 드라이브·Slack 같은 도구 연결과 작업 요령을 한데 묶은 꾸러미입니다. 사이드바의 ‘플러그인’에서 설치하고, 대화 중에 @로 불러 씁니다. 예전 ‘맞춤형 GPT’는 12월 11일 종료되니 플러그인으로 옮겨 두세요.

  • 업무 모드: Plus 이상은 웹·PC·휴대폰, 무료·Go는 PC 앱에서 제한적으로
  • 연결할 때는 필요한 권한만 허용
  • 결과 속 숫자·사실은 원본과 대조
업무 모드에 맡기기
@Google Drive 의 ‘3분기 영업’ 폴더 자료로 임원 보고 슬라이드 8장을 만들어 줘. 1장 요약, 2~6장 지역별 실적, 7장 위험 요인, 8장 다음 분기 계획. 숫자는 원본 자료에 있는 값만 써 줘.
결과

자료를 읽고 슬라이드 파일을 만들어 돌려줍니다. 중간에 “7장은 표로”처럼 방향을 바꿀 수 있고, 끝나면 숫자가 원본과 맞는지 꼭 확인하세요.

메모리 (Memory)

ChatGPT가 대화를 통해 나에 대한 정보를 기억합니다. 이름, 직업, 선호 언어, 말투 등을 자동으로 저장해 다음 대화에서 매번 설명하지 않아도 됩니다. 설정에서 언제든 확인·수정·삭제할 수 있습니다.

  • 한 번 알려주면 이후 대화에 자동 적용
  • 저장된 내용 직접 관리 가능
  • 원하지 않으면 메모리 기능 끄기 가능
입력
나는 스타트업 마케터야. 항상 짧고 실행 중심으로 답해줘.
결과 (메모리 저장 후)

저장 완료: "사용자는 스타트업 마케터. 답변은 짧고 실행 가능한 형태로."
이제 모든 대화에 자동 반영됩니다.

기능 골라 쓰는 순서 — 복사용 프롬프트

기능 이름을 몰라도 됩니다. 하려는 일을 말하면 ChatGPT가 알맞은 기능(Canvas·Deep Research 등)을 켭니다. 아래 두 개를 복사해 바로 써 보세요.

긴 보고서를 쓸 거야. Canvas를 열어서 초안을 만들고, 단락별로 골라 고칠 수 있게 해줘. 구성: 배경 / 현황 / 제안 / 기대효과, 각 단락 3~4문장. [주제·핵심 메모 붙여넣기]
다음 주제로 Deep Research 해줘: [주제]. 신뢰할 만한 출처를 각주로 달고, 서로 다른 관점을 비교해줘. 끝에 한 줄 요약 + 실무 시사점 3가지.

Codex — 코딩 에이전트 중급

업데이트 · 2026-09-27

Codex는 단순히 코드를 알려주는 것이 아니라 실제로 코드를 읽고, 여러 파일을 수정하고, 명령을 실행해 작업을 끝까지 수행하는 에이전트입니다. 코딩을 잘 몰라도 "이 기능을 추가해줘"라고 말하면 알아서 처리합니다.

가장 빠른 시작 — CLI

npm i -g @openai/codex codex

처음 실행하면 로그인 안내가 뜹니다. ChatGPT 계정(Plus 이상에 Codex 포함) 또는 OpenAI API 키로 로그인합니다. macOS·리눅스는 curl -fsSL https://chatgpt.com/codex/install.sh | sh로도 설치할 수 있습니다. 윈도우는 이제 PowerShell에서 바로 실행되며(윈도우 전용 샌드박스가 파일·네트워크 접근을 제한), 리눅스 도구가 꼭 필요할 때만 WSL2를 씁니다.

Codex 4가지 형태

CLI (터미널) 가장 빠른 시작. 대화형 실행·승인 모드로 자동 실행 범위 조절 (읽기만 / 수정 허용 / 전체 허용)
IDE 확장 (VS Code · Cursor) 에디터 안에서 직접 파일 읽기·명령 실행·수정. 작업 전후 Git 체크포인트 권장
Cloud / Web (chatgpt.com/codex) 격리 클라우드 샌드박스에서 작업. 변경사항 diff 검토 → 바로 Pull Request 생성
GitHub · Slack 연동 이슈 할당 또는 Slack 메시지로 Codex에 작업 위임. CI/CD 파이프라인 자동화
AGENTS.md 파일: 저장소 루트에 AGENTS.md를 두면 프로젝트 규칙·코딩 컨벤션·금지 사항 등을 Codex에 알려줄 수 있습니다. 팀 저장소라면 먼저 만들어두세요.

Codex 실전 예시

CLI 입력
로그인 폼에 이메일 유효성 검사를 추가해줘. 실패 시 붉은 테두리와 오류 메시지를 표시하고, 기존 테스트가 통과되는지 확인해줘.
Codex 동작

① 파일 분석: src/LoginForm.tsx, src/validators.ts, tests/login.test.ts 읽기

② 계획 제시: validators에 이메일 정규식 추가 / LoginForm에 상태 연결 / CSS 오류 스타일 추가

③ 실행 후 diff 표시 → 사용자 승인

④ 테스트 실행: npm test → 전체 통과 확인

기대 효과

  • “어느 파일을 고쳐야 하지?”를 찾는 시간이 줄어듭니다. Codex가 저장소를 읽고 고칠 곳과 계획부터 보여 줍니다.
  • 수정 → 테스트 실행 → 결과 확인을 에이전트가 이어서 하므로, 사람은 diff(바뀐 부분) 검토와 승인에 집중할 수 있습니다.
  • AGENTS.md에 팀 규칙을 적어 두면 누가 시켜도 같은 방식으로 작업해 결과가 고르게 나옵니다.

문제 해결

증상원인처방
로그인은 되는데 Codex를 쓸 수 없다고 나옴Codex가 포함되지 않은 요금제Plus·Pro·Business·Edu·Enterprise 요금제로 로그인하거나 API 키로 로그인
윈도우에서 샌드박스 설정이 실패함관리자 승인이 필요하거나 회사 보안 정책이 막음(오류 1385 등)IT 부서에 필요한 권한을 요청하고, 그동안은 공식 문서의 ‘권한 상승 없는(unelevated) 샌드박스’를 임시로 사용
팀 코딩 규칙을 자꾸 어김규칙을 매번 대화로만 전달저장소 루트에 AGENTS.md를 두고 금지 사항·테스트 명령을 적어 두기
수정 결과가 마음에 들지 않음작업 전 되돌릴 지점이 없음시작 전에 Git 커밋(체크포인트)을 남기고, diff를 확인한 뒤에만 승인
대화창 없이 스크립트·CI에서 돌리고 싶음대화형 모드만 알고 있음한 번 돌고 끝나는 codex exec 사용 — 헤드리스 실행 편 참고
더 깊이 쓰려면. 규칙 파일 작성은 AGENTS.md 편, 여러 작업을 나눠 맡기는 법은 Codex 서브에이전트, Claude Code와 함께 쓰는 법은 Codex 교차 활용 편을 보세요. 설치 방법·요금제 조건은 자주 바뀌니(작성 시점 2026년 9월) 아래 공식 문서로 한 번 더 확인하세요.
Codex CLI 시작하기 (OpenAI 공식) ↗설치 방법·지원 운영체제·로그인 방식·이용 가능한 요금제 윈도우에서 Codex 쓰기 — 샌드박스 (OpenAI 공식) ↗PowerShell 실행과 WSL2 중 고르는 기준, 설정 실패 시 해결법

새로운 프로젝트라면 레거시 Chat Completions 대신 Responses API + Agents SDK를 사용하세요. 멀티스텝 에이전트 구현이 훨씬 간단합니다.

Function Calling — AI에 실제 행동 능력 부여

AI 모델은 기본적으로 텍스트만 출력합니다. Function Calling을 쓰면 모델이 "이 함수를 이런 인자로 호출해야 한다"고 JSON으로 알려주고, 내 코드가 실제 실행한 뒤 결과를 다시 모델에 넘겨 최종 답을 완성합니다.

활용 예시

  • 예약 챗봇: 사용자가 "다음 주 화요일 2시로 예약해줘"라고 하면 모델이 create_booking(date, time) 호출
  • 재고 조회: "A 제품 재고 남았어?"에 check_inventory(product_id) 자동 실행
  • 슬랙 알림: 조건 충족 시 send_slack_message(channel, text) 호출로 자동 발송
더 깊은 API 활용은 심화 활용 페이지에서 Python SDK 예제, Agents SDK 아키텍처, 비용 최적화 팁까지 확인하세요.

활용 상황

예약·주문 봇자연어 요청을 캘린더·주문 API 호출로 연결
사내 데이터 조회“지난달 매출?”을 DB 조회 함수로 자동 실행
알림·업무 자동화조건이 맞으면 슬랙·메일 발송 함수 호출
구조화 출력답을 정해진 JSON 형식으로 강제해 시스템에 연결

사용 방법 — Function Calling 한 바퀴

너는 예약 도우미야. 사용자가 예약을 원하면 create_booking 함수를 호출해. 함수: create_booking(date 'YYYY-MM-DD', time 'HH:MM', people 숫자) 사용자: 다음 주 화요일 저녁 7시에 4명 예약해줘 → 실행하지 말고, 어떤 인자로 함수를 부를지 JSON으로만 알려줘.
모델의 함수 호출(JSON) · 예

create_booking(date='2026-07-14', time='19:00', people=4) — 모델은 실행하지 않고 ‘어떻게 부를지’만 제안합니다.

내 코드 실행 후 결과를 모델에

내 코드가 실제 예약 API를 부르고 결과(확정 · 예약번호 8821)를 모델에 돌려주면, 모델이 “7월 14일 오후 7시 4인 예약 완료”라고 최종 답을 만듭니다.

구조화 출력 · 입력

“아래 후기를 sentiment·score·keywords 필드의 JSON으로만 뽑아줘.”

결과

{ sentiment: 긍정, score: 0.9, keywords: [배송, 가격] } — 사람이 읽는 문장이 아니라 시스템이 바로 쓰는 데이터로 받습니다.

문제 해결

증상원인처방
함수를 안 부르고 말로만 답한다지시가 모호하거나 함수 설명 부족함수 이름·설명·파라미터를 구체적으로, “필요하면 반드시 함수를 써라”고 지시
엉뚱한 인자를 지어낸다형식·필수 제약이 느슨함파라미터에 타입·필수·예시를 명시하고, 서버에서 한 번 더 검증
JSON이 깨져 파싱 실패자유 서술이 섞임구조화 출력(JSON 스키마·강제 모드) 사용, 실패 시 재시도
함수를 부른 뒤 멈춘다실행 결과를 모델에 다시 안 넘김결과를 도구 메시지로 되돌려 최종 답을 생성하게
비용·지연이 커진다매 턴 함수가 많고 정의가 김함수 수를 줄이고 설명을 간결히, 자주 쓰는 건 캐싱
  • 함수 이름·설명·파라미터를 구체적으로 정의했는가
  • 모델의 함수 호출을 내 코드가 실제 실행하고 결과를 되돌리는가
  • 인자를 서버에서 한 번 더 검증하는가(환각 대비)
  • 중요한 출력은 JSON 스키마로 형식을 강제했는가

자주 묻는 질문

업데이트 · 2026-09-28
무료 플랜으로 충분할까요?

가벼운 질문·번역·글쓰기라면 충분합니다. 무료도 텍스트 대화는 사실상 무제한이고, 이미지·음성·심층 리서치·Codex를 조금씩 써 볼 수 있습니다. 한도에 자주 걸리거나 업무 모드·프로젝트·예약 작업이 필요해지면 Plus(월 ₩29,000)를 고려하세요.

모델은 뭘 골라야 하나요?

대부분은 기본값 그대로 두면 됩니다. 어려운 계산·분석이 필요할 때만 ‘생각하기’를 켜거나 깊이를 올리세요. GPT-6 계열은 주로 업무 모드와 Codex에서 쓰이므로, 채팅에서 모델 이름을 일일이 고를 필요는 크지 않습니다.

맞춤형 GPT가 없어진다는데, 어떻게 해야 하나요?

새 GPT 만들기는 10월 26일에 끝나고, 기존 GPT는 12월 11일에 종료됩니다(승인된 기업 워크스페이스는 2027년 2월 11일). 내 GPT 화면의 ‘플러그인으로 옮기기’로 지침과 파일을 옮길 수 있지만, 외부 연결(맞춤 액션)과 지난 대화는 자동으로 넘어가지 않으니 미리 정리해 두세요.

한국어는 잘 되나요?

잘 됩니다. 설정 → 맞춤 지침에 “항상 한국어 존댓말로”를 적어 두면 따로 요청하지 않아도 한국어로 답합니다.

내 대화가 AI 학습에 쓰이나요?

개인 요금제(Free·Go·Plus·Pro)는 기본적으로 모델 개선에 쓰일 수 있고, 설정 → 데이터 관리에서 끌 수 있습니다. Business·Enterprise는 기본적으로 학습에 쓰이지 않습니다. 정확한 정책은 OpenAI 개인정보 처리방침 ↗을 확인하고, 민감한 정보는 넣지 않는 것이 가장 안전합니다.

Codex를 쓰려면 뭐가 필요한가요?

모든 요금제에 Codex가 들어 있고, 무료·Go는 사용량이 제한적입니다. 가장 쉬운 길은 새 PC 앱의 Codex 모드이고, 터미널을 쓰는 개발자는 CLI로 시작합니다. 윈도우도 이제 PowerShell에서 바로 설치할 수 있습니다(→ Codex).

ChatGPT와 Claude, 뭐가 더 좋나요?

용도에 따라 다릅니다. ChatGPT는 이미지 생성, 음성 대화, 업무 모드와 Codex, 폭넓은 플러그인이 강점입니다. Claude는 긴 문서 분석과 글 품질, 대화 안에서 바로 고치는 문서·슬라이드(Docs·Slides), 내 PC 파일 작업이 강점입니다. 둘 다 무료로 써 보고 고르는 분이 많습니다(→ Claude 가이드).
